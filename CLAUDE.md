# Working with the owner

Must rules, every time:

- **Links for anything to look at or act on.** Whenever you ask the owner to
  look at, check, review, run, merge or release something, give a clickable
  link straight to it: the pull request, the Actions workflow to run, the
  file on GitHub, the live demo, the settings page. Never just name it.
- **Previews for anything to see.** Whenever you show a visual change (a
  critter, a page, a layout, a screenshot), send the image itself so it
  renders in the conversation; don't only describe it or point at a path.

Useful links:

- Pull requests: https://github.com/tharun-se95/ModsArena/pulls
- Release workflow (Run workflow on `main`): https://github.com/tharun-se95/ModsArena/actions/workflows/release.yml
- CI: https://github.com/tharun-se95/ModsArena/actions/workflows/ci.yml
- Live demo: https://tharun-se95.github.io/ModsArena/
- Releases: https://github.com/tharun-se95/ModsArena/releases
